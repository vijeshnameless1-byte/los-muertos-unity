# Los Muertos (Unity Prototype)

An open-world driving and crime sandbox I'm building in Unity as my first game project, with AI helping me learn along the way.

## Goal
A small, polished slice of a GTA-style game: drive a car, explore a city, take jobs, and evade police.

## Roadmap
- [x] Drivable car with chase camera
- [ ] Third-person character on foot
- [ ] Enter and exit vehicles
- [ ] Traffic and pedestrian AI
- [ ] Wanted / police system
- [ ] Missions
- [ ] City art, lighting, weather and audio

## Built with
- Unity 6 (LTS), C#
- Claude for code help and learning

## How to run
1. Install Unity Hub and a Unity 6 LTS editor.
2. Clone this repo.
3. In Unity Hub choose **Add project from disk** and select the cloned folder.
4. Open the main scene in `Assets/Scenes` and press Play.

If you see an input error: Edit > Project Settings > Player > Active Input Handling > **Both**.

## Controls
- W / S: accelerate and brake
- A / D: steer
